# Poké-Library Emulator

This is a simple web project that sets up a Game Boy Advance emulator with a few handy tabs:
- **Play**: where the emulator screen will go
- **Poké Harbour**: links out to the real Poké Harbour site for downloads
- **Upload**: lets you add your own `.gba` files
- **Library**: shows all the games you’ve added and lets you save/load states

---

## Live Site
You can try it here:  
[https://hk-citizen.github.io/Poke-library/](https://hk-citizen.github.io/Poke-library/)

---

## How it works
1. Go to the Harbour tab and grab a game from Poké Harbour.  
2. Upload the `.gba` file using the Upload tab.  
3. Your game will show up in the Library, ready to play.  
4. Use the Save/Load buttons to keep your progress.
